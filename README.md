# mon-restaurant-landing

Landing page minimaliste pour "Yellow Pub" — logo centré et deux boutons vers Menu Food et Menu Drink.

Fichiers ajoutés et modifiés:
- index.html : page d'accueil avec logo, titre "Yellow Pub", boutons Menu Food et Menu Drink, et QR code qui pointe vers l'URL GitHub Pages.
- styles.css : styles responsive
- README.md : notes et instructions
- .github/workflows/deploy-pages.yml : workflow GitHub Actions pour déployer sur la branche gh-pages

Liens Drive utilisés (fichiers externes actuellement reliés depuis Google Drive):
- Logo : https://drive.google.com/uc?export=download&id=1J11OUi-DFAEsY0nR2NMTpNN4yqmIwa8e
- Menu Food : https://drive.google.com/uc?export=download&id=1c3MuQ2nSvrDGcUYG6vboSDZLJWUAxbz0
- Menu Drink : https://drive.google.com/uc?export=download&id=1754-0QPj9vxTyZ4zrkljIU64S0kmFvef

Publication:
- Le dépôt est public : https://github.com/holbornboss-glitch/mon-restaurant-landing
- Le workflow GitHub Actions déploiera automatiquement le contenu vers la branche `gh-pages` après chaque push sur `main`.
- URL publique attendue (après déploiement) : https://holbornboss-glitch.github.io/mon-restaurant-landing/

Remarques / prochaines étapes possibles:
- Je peux téléverser les PDFs dans le dépôt pour éviter la dépendance à Google Drive.
- Je peux personnaliser les couleurs à partir du logo si tu veux.
- Une fois que GitHub Pages est actif (quelques minutes), je peux générer et t'envoyer une version PNG du QR si tu préfères un fichier local.

Si tu veux que je fasse l'une de ces actions, dis-le et je m'en occupe.
